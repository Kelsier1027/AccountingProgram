# 01 · 原始需求分析

> 記錄日期：2026-11-16

## 原始需求（照錄）

產生一個客製的記帳程式，需要能達成以下目標：

1. 不需架設網站或是 DB 便可儲存資料，透過將資料儲存在 GitHub 或是 Google 服務這類免費的服務
2. 有可視化的介面可以檢視或是操作，操作部分若是無可行方案，可以考慮透過 Claude Code 進行處理
3. 開發完成後必須能脫離電腦的依賴，在手機上或是其他電腦的瀏覽器中也能使用或檢視
4. 記帳部分要包括：目前所有資產、存款、股票（需依當前股價計算）、代繳款項（房租、電費；原文用字，功能名稱已改為「待繳」）、債務（學貸、信貸）、自己欠他人／他人欠自己的款項、載具中紀錄的消費、信用卡帳單與明細；載具明細與信用卡明細可能重複，必須能把兩者對應並合併為一筆，避免重複計算。

## 拆解與解讀

| # | 需求 | 解讀 | 驗收條件 |
|---|------|------|----------|
| R1 | 免伺服器、免資料庫 | 純靜態前端；資料是一個 JSON 檔，放在 **私有** GitHub repo，透過 GitHub REST API（Contents API）讀寫。Google Drive / Sheets 列為替代方案，不作為首版實作。 | 只有靜態檔案；資料寫入 `data/ledger.json` 並產生 commit。 |
| R2 | 可視化檢視與操作 | 瀏覽器 UI 可完成全部 CRUD；另提供 Claude Code 操作路徑（`CLAUDE.md` 說明資料格式 + `tools/ledger.mjs` CLI），處理大量匯入或複雜修正。 | 每類資料都能在 UI 新增、編輯、刪除；CLI 可匯入與對帳。 |
| R3 | 脫離電腦、手機可用 | 部署成靜態網站（GitHub Pages / Cloudflare Pages），做成 PWA（可加到主畫面、離線檢視）；響應式版面。 | 手機寬度（390px）可正常操作；任何瀏覽器登入同一 repo 即看到同一份資料。 |
| R4a | 資產、存款 | 帳戶（現金、銀行、電子支付）與其他資產（車、保單價值等）。 | 總覽頁顯示總資產與淨值。 |
| R4b | 股票依現價計算 | 持股（代號、股數、成本）× 最新股價；台股上市 `.TW`、上櫃 `.TWO`、美股；外幣依匯率換算台幣。瀏覽器直接抓股價會遇到 CORS，故由 **GitHub Actions 排程** 在伺服器端抓價並寫入 `data/prices.json`；UI 可觸發立即更新，也可手動輸入價格。 | 市值與未實現損益自動計算；顯示報價時間。 |
| R4c | 待繳款項 | 房租、電費、水費、電信等週期性帳單：金額、繳費日、週期、繳費紀錄、本期是否已繳。 | 列出本期未繳／即將到期項目；繳費會產生一筆支出。 |
| R4d | 債務 | 學貸、信貸、房貸等：原始本金、剩餘本金、利率、月付金、繳款日。 | 計入負債；可記錄還款並降低餘額。 |
| R4e | 個人借貸往來 | 我欠別人／別人欠我，可部分還款、結清。 | 應收計入資產、應付計入負債。 |
| R4f | 載具消費 | 匯入財政部電子發票平台的 CSV 匯出（M/D 格式），含品項明細。 | 匯入後成為支出交易，保留發票號碼與品項。 |
| R4g | 信用卡帳單與明細 | 卡片、每期帳單（結帳日、繳款截止日、應繳金額、已繳）、刷卡明細（CSV 匯入，可設定欄位對應，或手動輸入）。 | 未繳卡費計入負債。 |
| R4h | 載具 ↔ 信用卡去重合併 | 對帳引擎：以金額、日期差、商家名稱相似度評分；高信心自動配對，其餘列為建議由使用者確認；支援一筆刷卡對多張發票（同日同店拆單）。配對後只計算一次（金額以刷卡為準，類別與品項取自發票）。 | 同一消費出現在兩邊時，支出統計只算一次；可解除配對。 |

## 隱含需求（推導）

- **隱私**：財務資料不可放在公開 repo。資料 repo 必須私有；權杖（fine-grained PAT）只存在使用者瀏覽器的 localStorage，不寫進程式碼。可選擇用密碼對資料做 AES-GCM 加密後再上傳。
- **多裝置同時編輯**：手機與電腦可能各自修改，要用「以記錄為單位、依 `updatedAt` 合併 + 刪除標記」處理衝突，不能整份覆蓋。
- **台灣慣例**：新台幣為本位幣；台股漲紅跌綠；介面使用繁體中文。
- **離線**：沒網路時可檢視上次同步的資料；可以先改，之後再同步。
- **可攜／備份**：可匯出、匯入 JSON；Git 歷史本身就是版本紀錄。

## 不在範圍（首版）

- 自動登入銀行或財政部平台抓資料（需要帳密或憑證，也有法規風險）——改用 CSV 匯入。
- Google Drive 儲存後端（保留介面，未來可加）。
- 多人共用帳本、預算規劃。
